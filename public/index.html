M

Gmail & college email

Connect each Google account separately. Saha reads your latest 10 inbox emails from the last 14 days per account.

Google setup · about 5 minutes

  1. Open Google Cloud Console ↗ and enable Gmail API.
  2. Configure Google Auth Platform → Branding and Audience. Add both email addresses as test users if External.
  3. Create an OAuth client → Web application.
  4. Add this redirect URI:http://localhost:3000/auth/google/callback
  5. Add GOOGLE_CLIENT_ID and GOOGLE_CLIENT_SECRET to .env, then restart the server.
  6. Connect your personal account, then repeat for college. Your college admin may need to allow access.

Your space stays yours

Tasks, notes, chat, emails, and Google tokens are saved in this computer’s ignored .data folder. API keys stay on the server in .env.

Only open this local app on a trusted computer. Closing it stops reminders. Gmail drafts open for you to review and send.

This prototype runs locally. A hosted, multi-user version needs authentication and encrypted token storage.
